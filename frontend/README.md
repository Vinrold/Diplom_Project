# Клиентская часть проекта

## Структура

В корне фронтед части лежат файлы `.env` с переменными окружения (например, ссылка на сервер), `index.html` - базовый файл сайта, `package.json` с зависимостями (библиотеками) `js` и `react`, `vite.config.js` с настройками инструмента сборки `Vite`, а также папки:
- `/public` - статические файлы (например, favicon для иконки во вкладке браузера);
- `/src` - логика фронтенд части.

### Src

Назначения файлов и папок:
- `index.css` - главная таблица стилей;
- `main.jsx` - точка входа в `React` приложение;
- `App.jsx` - основной файл;
- `api/` - файлы с функциями для работы с сервером;
- `assets/` - фото, видео и т.д., необходимые для страниц сайта;
- `components/` - переиспользуемые фрагменты для страниц сайта;
- `routes/` - сгруппированные в одном месте маршруты (ссылки) сайта;
- `hooks/` - папка для самописных хуков;
- `pages/` - папка для страниц сайта;
- `utils/` - вспомогательные инструменты (например, усложненная валидация данных на клиенте);


## Запуск клиента

Находясь в папке `frontend`, выполните команду:
```cmd
npm run dev
```

Перед этим убедитесь, что БД и сервер запущены
