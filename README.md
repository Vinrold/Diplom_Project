# Главная страница репозитория

## Структура проекта

- `backend` - папка с серверной частью приложения. Сервер написани на `Python`+`FastAPI`, инструкция по запуску и подробное описание находится в папке `backend/README.md`

- `frontend` - папка с клиентской частью приложения. Клиент написани на `React`, инструмент сборки - `Vite`, инструкция по запуску и подробное описание находится в папке `frontend/README.md`

- `docker-compose.yml` - описание сервиса `docker` с БД `postgresql`, развернутой в контейнере. К ней подключается бэкенд.
