# Серверная часть проекта

## Структура

В корне бэкенд части лежат файлы `.env` с переменными окружения (например, ссылка на БД), `requirements.txt` с библиотеками python, и папка `/app`

### App

Назначения файлов и папок:
- `main.py` - точка входа с запуском сервера;
- `config.py` - выгрузка переменных окружения из `.env`;
- `database.py` - обеспечение работы с БД;
- `dependencies.py` - группировка зависимостей (импортов) в одном файле;
- `models/` - модели для каждой сущности (будут переводиться в таблицы и строки в БД через ORM);
- `schemas/` - схемы Pydantic для проверки корректности данных от форм на клиенте
- `routers/` - сгруппированные по сущностям энедпоинты API

## Запуск сервера

Находясь в папке `backend`, выполните команду:
```cmd
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Перед этим убедитесь, что БД запущена
